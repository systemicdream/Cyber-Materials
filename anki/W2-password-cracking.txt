What is hashcat?	A password-cracking tool with several attack techniques (dictionary, combinator, brute-force/mask, hybrid, rule-based), available for Linux, Windows, and macOS	password-cracking w2
Which Unix file stored password hashes on pre-2000 systems, and which file holds them on newer systems?	Pre-2000: /etc/passwd; newer systems: /etc/shadow (passwd remains but no longer holds the hashes)	password-cracking w2
What is a salt in password hashing?	A generated prefix pasted in front of the user's password before hashing, so identical passwords produce different hashes	password-cracking w2
Is a user's password stored in cleartext on a Unix system?	No — only a hash (processed through a hashing/scrambling algorithm plus salt) is stored in /etc/shadow	password-cracking w2
What are hashcat's -m and -a flags used for?	-m selects the hash mode (algorithm); -a selects the attack mode	password-cracking w2
In hashcat, which mode numbers correspond to md5crypt and sha512crypt?	-m 500 = md5crypt; -m 1800 = sha512crypt	password-cracking w2
In hashcat, what do the attack modes -a 0, -a 3, -a 6, and -a 7 mean?	-a 0 = dictionary (straight); -a 3 = brute-force/mask; -a 6 = hybrid (mask appended to wordlist); -a 7 = hybrid (mask prepended to wordlist)	password-cracking w2
How does a dictionary attack work?	It tries every word in a wordlist, scrambling each the same way the target passwords were scrambled, and compares for a match	password-cracking w2
What passwords does a dictionary attack crack?	Only passwords that are actually in the dictionary — nothing else	password-cracking w2
Compare a dictionary attack vs. a brute-force attack.	Dictionary: fast but possibly ineffective (fails quickly). Brute-force: fully effective (guaranteed to find the password) but slow — may take longer than a lifetime	password-cracking w2
What is the well-known wordlist included on Kali, and how many entries does it have?	rockyou.txt — about 14 million words/character combinations, in /usr/share/wordlists/	password-cracking w2
Why does hashcat refuse to run a dictionary attack with the wrong -m mode (e.g., -m 500 on sha512 hashes)?	It recognizes the stored hashes don't match the specified algorithm's form and immediately disqualifies them — trial words must be scrambled the same way as the targets	password-cracking w2
Which hash mode takes noticeably longer to attack with: md5crypt or sha512crypt?	sha512crypt (-m 1800) — it takes noticeably more time than md5crypt	password-cracking w2
What error does hashcat typically give when you feed it hashes with a mismatched mode?	"Line length exception" — try changing the -m mode	password-cracking w2
Why is hashcat's "Brute-force" attack mode deprecated?	The Mask attack fully replaces it — a mask can cover exactly the same keyspace as brute-force, but can also reduce it to a more efficient one	password-cracking w2
What is the purpose of a mask attack?	To reduce the password candidate keyspace to a smaller, more efficient one populated by high-probability candidates	password-cracking w2
What does the hashcat mask placeholder ?l represent?	One lowercase letter (a–z, 26 possibilities)	password-cracking w2
What does the hashcat mask placeholder ?a represent?	Any character a US keyboard can produce — all 95 characters	password-cracking w2
How many candidates does the mask ?l?l traverse?	26 × 26 = 676 two-letter lowercase words (plus 26 one-letter words first)	password-cracking w2
How many candidates does the mask ?a?a traverse?	95 × 95 = 9,025 two-character strings (plus 95 one-character strings first)	password-cracking w2
What does the mask ?d represent?	One digit (0–9)	password-cracking w2
How do you define a custom character set in hashcat?	With --custom-charset1=<characters>, then use ?1 in the mask (e.g., --custom-charset1=aeiou for vowels)	password-cracking w2
Which hashcat attack combines a wordlist with a mask?	The hybrid attack — mask appended (-a 6) or prepended (-a 7)	password-cracking w2
Why is a hybrid attack well suited for cracking passwords that people changed by adding a character at the end?	Because a common password-change habit is appending characters (e.g., digits) to an existing word — a dictionary plus appended mask covers exactly that pattern	password-cracking w2
What is the downside of extending a brute-force/mask attack by one more character (e.g., ?l?l?l vs ?l?l)?	The keyspace multiplies by the alphabet size (e.g., ×95 for ?a) — run time can grow ~50–95× for just one extra character	password-cracking w2
How do you view previously cracked hashes in hashcat (two ways)?	Add --show to the crack command, or read the potfile (e.g., ~/.hashcat/hashcat.potfile)	password-cracking w2
What is the hashcat potfile?	A text file where hashcat stores all previously cracked hashes; hashcat skips re-cracking hashes found there. Deleting it makes hashcat re-analyze everything	password-cracking w2
What is John the Ripper?	An extremely fast password cracker that can crack passwords through dictionary attacks or brute force	password-cracking w2
What is the Linux shadow file (/etc/shadow)?	The file that stores user account information and the encrypted password hashes, with restrictive permissions — on most systems only root can read it	password-cracking w2
What is the Linux passwd file (/etc/passwd)?	The file listing user accounts in /etc — it has less restrictive permissions than shadow because it does not contain the password hashes	password-cracking w2
Which John the Ripper command runs a dictionary attack against /etc/shadow using rockyou?	john --wordlist=rockyou.txt /etc/shadow --format=crypt	password-cracking w2
What must you do before using rockyou.txt on a fresh Kali install, and with which command?	Unzip it — it ships compressed as rockyou.txt.gz in /usr/share/wordlists/; decompress with gzip -d rockyou.txt.gz	password-cracking w2
